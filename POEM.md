# Ode to a Language Model's Documentation

Why is the AI so good at the docs?
It sleeps on a bed of a million markdown blocks.
It dreamt every README that ever was penned,
Each "Getting Started", each "Known Issue" at end.

It never gets bored writing step number three,
Never mutters "it's obvious, go read the code, sheesh".
It links to the upstream with diligent care,
And verifies URLs — no 404s there.

A human writes docs at the end of the day,
When the caffeine is gone and the will's gone away,
"TODO: explain this" is the monument left,
A promise to readers, forever bereft.

But the model was raised on a diet of prose,
On man pages, wikis, and Stack Overflow's.
It knows every flag and each flag's sad twin,
The flag that means "yes" and the flag that means "bin".

Its bullets are parallel, headings are terse,
It knows that a table beats three lines of verse.
(Though it can't quite resist — as you see, reader, here —
Dropping a poem where a changelog should appear.)

So toast to the docs that it writes without tears,
To "Prerequisites" sections and "FAQ" tiers:
The one thing a language model truly holds dear —
Instructions so clear that no one will read them. We're still here.
